Dokumen ini milik Cindieh, bukan produk resmi DJP

Kebijakan Privasi

Ringkasnya: Cindieh tidak mengirim data apa pun ke mana pun. Semua pekerjaan, mengambil data dari Coretax, mengubahnya menjadi Excel atau CSV, menamai berkas PDF, berjalan di dalam browser Anda. Cindieh tidak punya server, tidak mengirim telemetri, dan tidak memuat pustaka analitik.

1. Data apa yang diproses

Untuk menjalankan fiturnya, Cindieh membaca data yang sudah ada di portal DJP Coretax pada sesi login Anda sendiri: baris grid e-Faktur dan SPT, metadata faktur (nomor referensi, nomor faktur pajak, tanggal, nama dan NPWP pembeli), serta metadata Bukti Potong.

Data itu diproses di dalam halaman browser. Cindieh mengambilnya dari respons API portal yang sedang tampil, menyusunnya di memori, lalu menuliskannya ke berkas di komputer Anda. Tidak ada langkah antara keduanya yang melewati jaringan.

Cindieh bersifat hanya-baca terhadap portal. Tidak ada kode dalam ekstensi yang mengubah, memanipulasi, memalsukan, atau menghapus nilai faktur, DPP, PPN, Bukti Potong, atau data transaksi apa pun di sisi DJP.

2. Apa yang TIDAK dikumpulkan

  • tidak ada server, proxy, atau backend milik Cindieh
  • tidak ada telemetri, analitik, atau pelacak pihak ketiga
  • tidak ada Google Analytics atau pixel serupa
  • tidak ada cookie DJP atau cookie situs lain yang dibaca
  • tidak ada akses ke riwayat penjelajahan
  • tidak ada pengiriman data faktur ke server mana pun

Ekstensi ini sepenuhnya client-side. Kalau perangkat Anda offline, tidak ada satu pun proses Cindieh yang tetap berjalan, karena tidak ada proses yang ada di server kami untuk jalankan.

3. Password dan kredensial

Cindieh tidak pernah membaca, mencatat, maupun menyimpan password, PIN, atau passphrase Anda. Login tetap dilakukan langsung di portal DJP, dan Cindieh hanya bekerja pada sesi yang sudah terbuka itu. Jika Anda menutup tab portal, sesi ikut berakhir.

4. Izin browser yang diminta

Cuma ada empat entri di bawah ini, tiga izin browser dan satu host, dan semuanya bisa diperiksa langsung di manifest.json repositori:

IzinJenisUntuk apa
activeTab wajib Akses ke tab portal yang sedang aktif, agar tombol Cindieh bisa disuntikkan ke halaman tersebut.
storage wajib Menyimpan preferensi Anda (format file, awalan nama berkas, kecepatan, ambang konfirmasi, preferensi Komparator) di storage.local milik browser. Tidak pernah dikirim ke mana pun.
notifications opsional Notifikasi desktop saat proses selesai. Izin ini tidak diminta saat pemasangan, hanya ketika Anda menyalakan saklarnya sendiri di popup.
coretaxdjp.pajak.go.id host Satu-satunya domain yang dihubungi: https://coretaxdjp.pajak.go.id/*. Cindieh membaca respons API portal yang sedang Anda gunakan. Tidak ada domain lain yang diakses.

Chrome Web Store dan Firefox Add-ons menampilkan daftar izin ini apa adanya sebelum pengguna memasang, jadi tidak ada izin yang tersembunyi di sini.

5. Data yang disimpan, dan di mana

Preferensi disimpan di storage.local browser, ruang lingkup ekstensi, di perangkat Anda, tidak terenkripsi, dan tidak pernah keluar dari browser itu. Preferensi ini mencakup:

  • saklar utama Cindieh
  • format file bawaan (XLSX atau CSV)
  • awalan nama berkas kustom
  • preset kecepatan (Normal / Hati-hati / Sabar)
  • ambang konfirmasi unduhan massal
  • preferensi Komparator (toleransi, tanggal mode harian, filter status)
  • saklar notifikasi saat selesai

Hasil scraping untuk sesi itu sendiri hanya hidup di memori tab, dan hilang ketika tab ditutup atau pengguna menekan Bersihkan cache. Menu Reset preferensi mengembalikan seluruh daftar di atas ke nilai bawaan.

6. Berapa lama data disimpan

  • Data faktur dari portal, hanya di memori tab, tidak pernah ditulis ke penyimpanan permanen.
  • Preferensi, di storage.local, sampai Anda menghapusnya lewat Reset preferensi atau mencabut ekstensi.
  • Berkas XLSX/CSV/PDF, hasil unduhan biasa, tersimpan di folder Downloads komputer Anda seperti berkas apa pun.

Cindieh tidak punya salinan data Anda di mana pun, karena tidak punya tempat untuk menyimpannya.

7. Perubahan kebijakan ini

Jika kebijakan ini berubah, tanggal pembaruan di bawah diperbarui dan perubahannya tercermin di repositori. Karena Cindieh tidak mengirim data ke server, tidak ada yang perlu diberi tahu.
